# AgenticED

AgenticED is a professional association for practitioners who use AI agents in customer education, training, certification, and curriculum development. Our guilds build and freely share **open-source AI agents and agent skills under the MIT License**. We also host educational programs where practitioners can share what they learn from using these assets.

[Explore the guilds](https://agentic-ed.org/guilds) · [Browse the repositories](https://github.com/orgs/Agentic-ED/repositories) · [Visit AgenticED](https://agentic-ed.org/)

## Find an asset you can use

Start with the work you want to do. An **agent skill** gives an AI environment instructions for a particular task and may include scripts, examples, or reference files. An **agent** uses instructions and tools to carry out a workflow. Download the asset from its repository and check its README for setup, dependencies, and compatibility with your environment, such as Claude, Gemini, or Codex.

For skills shared across guilds, start with [Agentic-ED/skills](https://github.com/Agentic-ED/skills).

## Find your guild

Each guild focuses on one area of practice and takes its name from a group of animals. The animal is also the guild’s AI steward. Members choose priorities, the steward helps review contributions, and human leads oversee routine releases.

| If you work on… | Explore | Steward |
|---|---|---|
| Community and events | The Ostentation, the home guild every member joins | Peacock |
| Curriculum development | The Colony | Beaver |
| Customer education | The Exaltation | Lark |
| Training | The Romp | Otter |
| Certification | The Parliament | Owl |

[See all guilds and their repositories](https://agentic-ed.org/guilds)

## Contribute something you’ve learned

Bring your own AI environment to build or improve an asset. A useful contribution can be small: an example input that exposes a limitation, a clearer instruction, or a test that shows whether a skill does what it claims.

1. Choose the guild closest to the work. Read its repository instructions and check open issues for related efforts.
2. Open an issue to describe the task or propose an agent or skill. If you already have a change ready, follow the repository’s pull request process.
3. Include a sample input, the outcome you expected, what actually happened, and the AI environment you tested. Use examples you have permission to share publicly.

[Find a guild to contribute to](https://agentic-ed.org/guilds)
